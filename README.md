## GeoCheck Checador

La aplicación está en la carpeta `geocheck/`.

### Ejecutarla en tu computadora

1. Instala Node.js 18 o posterior desde https://nodejs.org/.
2. Descarga o clona este repositorio y abre una terminal dentro de la carpeta `geocheck`.
3. Ejecuta:

```bash
npm install
npm run dev
```

4. Abre la dirección local que muestre Vite, normalmente http://localhost:5173.

Para usar cámara y GPS desde un teléfono, ejecuta `npm run dev:https` y usa la dirección HTTPS que muestre Vite. Acepta el certificado local de desarrollo si el navegador lo solicita.

Consulta `geocheck/README.md` para más detalles y advertencias importantes. Esta versión es una demostración: los NIP son de ejemplo y los registros se guardan en el navegador, no en un servidor seguro.
